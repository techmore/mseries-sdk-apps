# Home Storage

Generated by `msdk gen`; SDK format 1.

On a supported Linux GTK 4.20+ development host, with Rust 2024, pkg-config,
GTK development headers, Wayland development headers and wayland-scanner installed:

```sh
cargo build
cargo test
cargo run
```

`src/lib.rs` exposes typed records, `State`, `Message::into_event` and the embedded
description. Edit `app.ui.json` for views/rules, or use a new output directory to
regenerate models after changing types. Keep the SDK checkout at `/work/sdk`;
the generated project uses explicit local dependencies and its own Cargo workspace.

The executable runs the real GTK Host with the description's update rules and
built-in services. Custom services/feeds require an app-local `Services` adapter
and `Host::open_with`; generation does not implement those backends. Panel
placement requires the documented Pantheon shell protocol and target-host tests.
Build/launch success is separate from visual, accessibility, service, packaging
and installed desktop acceptance. No install or background service is performed
by generation.
